## 长期固定通道 `app-v1`

客户端硬编码指向这个 tag，**地址永不变更**，只刷新其中的文件内容：

- `app-version.json` — 应用内更新清单，决定客户端看到的最新版本与可用增量包
- `online-endpoint.json` — 在线音色的服务端点发现

## 字体包 `fonts-v1`

17 款可下载中文字体，均为 SIL OFL 授权的开源字体，在应用内「阅读设置 → 字体」按需下载。
该 tag 以追加为主，既有字体文件不做原地替换。

**音色包按内容寻址，一经发布绝不覆盖。** 客户端用硬编码 SHA-256 校验下载结果，
原地替换会让已发布的各版本同时校验失败；内容变更时启用新 tag。
`app-v1` 是唯一例外——它按设计就是可变清单，客户端不对它做摘要校验。
