**每个已公开发布版本的 APK 与增量包都长期保留**（自 `v1.1.4` 起的策略）。
早先的约定是只留最新一版，`v0.138.0`–`v0.147.0` 的 Release、tag 与全部资产已据此删除，
不可恢复；此后不再清理。删旧包本就不影响任何用户升级——客户端的差分基线取
**设备上已安装的那份 APK**（`applicationInfo.sourceDir`），不从远端取旧包；
保留是为了让每一版记录在案的字节数与 SHA-256 始终可被回验、任意历史版本可被重新取回。
**当前版本的完整包尤其必须保留**：它是下一版增量包的基线，删掉就无从生成增量。

**版本化二进制与内容寻址的音色包一经发布绝不覆盖。** 客户端用硬编码 SHA-256
校验下载结果，原地替换会让已发布的各版本同时校验失败；音色包内容变更时启用新 tag。
`app-v1` 是唯一例外——它按设计就是可变清单，客户端不对它做摘要校验。

## 版本号规则

`x.y.z`：仅修 BUG 或界面参数微调改 `z`；增删功能、性能优化、小型重构改 `y`；
大幅重构、数据结构不兼容、功能重做改 `x`。`x` 变更时 `y`、`z` 归零，`y` 变更时 `z` 归零。
