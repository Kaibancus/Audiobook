# 阅文听书 Lullaby · 分发仓库

Android 原生阅读与在线朗读应用「阅文听书」（英文资源名 **Lullaby**）的公开资产仓库。
**本仓库不含源码**，只托管 APK、差分包、稳定清单和运行时下载资源。

## 长期固定通道 `app-v1`

客户端硬编码指向这个 tag，地址保持不变，只刷新其中的文件内容：

- `app-version.json` — 应用内更新清单，当前指向 v2.1.0 / code181
- `online-endpoint.json` — 在线音色服务端点发现

## 字体包 `fonts-v1`

应用内提供多款 SIL OFL 授权中文字体按需下载。该 tag 以追加为主，既有字体文件不原地替换。
